# AgentForge Frontend

A lightweight React + Vite + Tailwind frontend for AgentForge.

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

## Project structure

- `src/main.jsx` — app entrypoint
- `src/App.jsx` — root layout and state
- `src/api.js` — API helper functions
- `src/components/` — UI sheets and panels
